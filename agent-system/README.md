# 众仁 · 代理与佣金管理系统

本地可运行的管理后台和代理工作台。使用 Python 3.11+ 标准库与 SQLite，无需安装 npm 包、数据库服务或云账号。不是只展示数据的 HTML；订单、账户、佣金和审计记录均保存在磁盘。

## 启动

双击 `启动众仁代理系统.command`，或在本目录运行：

```sh
python3 server.py
```

打开 <http://127.0.0.1:8787>，首次使用自行创建管理员账号（密码至少 12 位）。正式环境没有预设管理员或演示数据。关闭终端即停止服务；下次启动继续使用同一份数据库。代理账号由管理员创建，生成的临时密码只在创建成功时显示一次。

当前服务只绑定本机。代理工作台可以在此机器登录验证；尚未部署成能从其他设备访问的线上平台。收付款通过管理员核对凭证后登记，不连接银行、支付网关或外部 AI 模型账户。

## Sub-admin / 个人推广工作台

现有代理账号均可作为个人 sub-admin 登录；只能查看和跟进自己的客户、购买意向、订单、佣金和业绩，不管理下级代理或团队订单。管理员负责开户、定制报价、确认收款、退款、佣金审核与结算。

1. 登录 `demo.subadmin`（演示密码同上），在总览或「推广中心」查看专属推广码、课程推荐链接，复制可粘贴到 WhatsApp 的文案。
2. 客户打开 `/recommend?ref=推广码`，无需登录即可选择课程、留下联系方式和需求。推广码决定代理归属；它不是折扣码。
3. 「客户跟进」展示本人的意向，可标为跟进中或关闭，保存跟进记录。已有订单客户也列在同一页。
4. 确认客户 Token 账户后，将意向转成待收款订单。后端固定原代理、课程、人数和客户姓名；重复提交不重复建单。超过 100 人的定制方案由管理员报价。
5. 购买意向和订单草稿均不产生业绩或佣金。后续沿用现有的收款、晋升、退款流程。

推荐页面只公开代理显示名称、推广码和课程目录；客户资料只给对应代理和管理员查看。停用代理后，其推广码不可再提交。

**本地服务的链接只在这台电脑有效。** 对外发送前需部署服务及正式网址；当前未发布公共网站，也没有在线付款或 WhatsApp 自动发送。

## 已实现的工作流程

1. 管理员创建代理，可指定已有推荐人。客户与业务员共用一种角色；已有合伙人须填写资格依据。
2. 管理员或代理录入课程订单。标准套餐金额由服务端锁定；超过 100 人的定制报价由管理员填写。
3. 管理员确认业务操作口径后，在「分润规则」启用收款记账。未确认前可开户、录单，但不能计入正式业绩。
4. 核实全额到账后登记凭证和税费。事务一次完成订单收款、佣金计提、Token 赠送、年度个人业绩更新与晋升。
5. 佣金审核后进入待结算余额。完成线下转账后登记付款凭证；系统不执行实际银行转账。
6. 全额退款撤回该单业绩、佣金和 Token。已结算佣金产生负数追回台账，后续佣金先抵扣再结算。
7. 管理员查看网络、账户余额及操作记录。代理只能查看自己的订单、业绩、佣金和结算；看不到其他客户、代理联系方式或全局审计。
8. 可导出订单、佣金和付款 CSV；导出遵循当前账号权限。

## 商业规则与启用状态

已确认并实现：

- 业务员直佣 20%，合伙人直佣 30%。
- 个人业绩按马来西亚自然年累计，RM 69,800 达标晋升；跨年业绩清零、身份保留。不是团队业绩或本人缴费金额。
- 达标那一单仍按成交前身份计佣，新身份从下一单生效。
- 渠道总佣金不超过 30%，交付费单列。
- 全额退款回撤业绩、佣金和 Token，自动晋升者年度业绩跌破门槛后恢复业务员。
- 操盘手三个档位赠送 300 / 680 / 1,000 Token 到订单关联账户。
- 架构师：基础版 RM 99,800、成长版 RM 119,800、规模版 RM 139,800；超过 100 人单独报价。

仍需业务确认，初始数据库因此**不启用收款记账**：

- 全额到账后计佣及多人套餐每单一个账户一份 Token 的口径。Token 可选择到账后自动发放，或管理员确认后手动发放；未选择时点时不可启用。
- 交付费 10% 是否适用于全部课程。界面可选全部课程或仅 AI 架构师企业定制课程；未选择范围时不可启用。
- 架构师 50 / 70 人边界尚待确认，系统保留相邻档位的重叠选择，不擅自重定价。
- A/B 白板的各级奖励未确认，因此默认不发上级佣金。管理员可明确设置逐级奖励百分比；业务员直佣后的渠道额度最多 10%，合伙人直佣 30% 无额外额度。超过上限会拒绝发布。

「分润规则」勾选启用代表管理员确认列明的操作口径，不是软件已自动取得业务批准。隔离测试中启用的规则不会复制到正式库。

## 账务约束

- 金额以整数分存储，逐条佣金四舍五入至分；另检查金额合计不超渠道上限。
- 支付确认、退款、结算通过 SQLite `BEGIN IMMEDIATE` 串行事务执行；并发重复收款不会重复计佣。
- 订单保存规则版本、成交身份、收佣链及各条金额快照；后续规则变更不追溯已收款订单。
- 推荐关系开户后固定；停用上级且其在应收佣链中时，暂停该链路收款，避免静默吞掉奖励。
- 默认年度以 `Asia/Kuala_Lumpur` 自然年计。跨年重置在首次读取工作台或收款时执行；退款只扣减该订单所属年度的当前业绩，不错误扣减下一年业绩。
- 保留跨年身份时，退款后重新核对历年有效成交：只要仍有一个年度达标就保留身份；只有达标资格均被退款撤销时才恢复业务员。新年度业绩本来较低不会抹去上一年仍有效的晋升资格。
- 当前支持全额退款，不支持分期收款、部分退款、跨币种或实际支付执行。
- 手工录入的已有合伙人资格有独立依据，不因其个人业绩退款自动取消；由业绩自动晋升者按门槛降级。
- Token 是本系统账本余额。未对接外部模型平台，不能据此声称外部账户已充值。

## 数据、安全与备份

正式数据位于 `data/zhongren.sqlite3`；不要删除 `data/`。密码采用 PBKDF2-SHA256 + 独立盐，数据库不存明文密码。登录会话 12 小时有效，HttpOnly / SameSite Cookie、CSRF 校验、服务端角色权限和 Host/Origin 校验保护本机访问。

在线一致性备份：

```sh
python3 backup.py ./data/backups/zhongren-2026-10-12.sqlite3
```

备份包含账号哈希和全部账务，请妥善保管。恢复时先停止服务，将现有 `data/` **整个目录改名保留**，建立新 `data/` 并把备份复制为 `zhongren.sqlite3`。不要把备份覆盖到仍打开的数据库或残留旧 WAL 文件上。然后重新启动服务。

正式环境没有默认密码；管理员密码遗失需维护者执行受控的本机恢复流程。正式对外部署还需 HTTPS、生产级服务托管、备份策略与账号恢复渠道；当前没有公开部署。
