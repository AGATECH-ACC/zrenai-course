# 众仁 AI · 课程与代理管理

AI 课程方案、代理推广、订单、佣金、年度晋升与退款管理系统。

## 项目内容

- `agent-system/`：Python + SQLite 管理后台、代理个人工作台及课程推荐页面。
- `index.html`：课程与合作方案说明。
- `AI课程与合作方案_确认稿.html`：可独立分享的方案确认稿。

## 本地运行

需要 Python 3.11 或以上，无需第三方 Python 依赖。

```sh
cd agent-system
python3 server.py
```

打开 http://127.0.0.1:8787，首次启动创建管理员账号。

### 独立演示环境

```sh
cd agent-system
python3 server.py --demo
```

打开 http://127.0.0.1:8789。首次启动会生成独立的演示数据库，重启保留测试进度。

| 用途 | 账号 |
| --- | --- |
| 管理员 | `demo.admin` |
| 个人推广工作台 | `demo.subadmin` |
| 晋升测试 | `demo.sales` |
| 合伙人 | `demo.partner` |
| 退款降级 | `demo.refund` |
| 已付佣金追回 | `demo.payout` |

上述虚构演示账号共用密码 `ZhongrenDemo2026!`，仅用于本地演示。正式环境没有默认密码或示例账务。推广码在开户时生成，在「推广中心」查看；不会固定使用某台电脑上的示例码。

## 主要功能

- 管理员开户与代理独立登录；个人工作台只管理自己的客户和订单。
- 推广码、课程推荐链接、购买意向、客户跟进及意向转订单。
- 业务员直佣 20%、合伙人直佣 30%；渠道佣金上限 30%，交付另计。
- 年度个人成交 RM 69,800 自动晋升，下一单起按新身份计佣。
- 全额退款撤回业绩、佣金和 Token；已付佣金追回与后续抵扣。
- 规则版本快照、审计、CSV 导出与一致性数据库备份。


详细业务口径、测试案例、数据备份及使用说明见 [系统说明](agent-system/README.md)。

## 部署状态

当前版本为本机运行版本，尚未部署为公共网站。线上部署需要支持 Python 的服务、持久数据库存储、HTTPS，以及生产登录与初始化配置。GitHub Pages 只能托管静态方案页，无法运行此后台。

本仓库不包含本地数据库、客户资料、登录会话或环境密钥。演示数据由代码生成，不能作为线上生产账户使用。
